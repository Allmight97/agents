# Wait, What

The user did not understand where you got to. Re-pitch the last message:

- Give a little context first.
- Use short, plain sentences in ASD-STE100 Simplified Technical English.
- Use the project's own terms, as its docs and code define them.
- List every decision still waiting on the user. Give each one its link when it
  has one, what it changes, the evidence, and your pick.
