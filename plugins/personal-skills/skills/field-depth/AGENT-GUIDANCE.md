# Agent Guidance for Professional Work

Read when writing a skill, persona, or other agent-facing guidance for
professional work. Bake these rules into the default behavior; do not only
mention the skill:

- The [Depth opener](SKILL.md#depth-opener) runs before search or a hard
  decision.
- Hard evidence gates before ranking. When the user's judgement and a model
  ranking disagree, the user's wins.
- Raw sources only. Do not invent numbers or treat another agent's recap as
  evidence.
- Name one next concrete step when the user is stuck.

Use [writing-for-agents](../writing-for-agents/SKILL.md) for how to place
those rules.
